# Notification System

A React frontend application for viewing campus notifications.

## Tech Stack

- React
- JavaScript
- Material UI
- Vanilla CSS

## Features

- View campus notifications
- Filter notifications by type
- Priority inbox
- Unread count
- Mark notifications as viewed
- Logging middleware integration
